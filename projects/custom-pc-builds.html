Custom PC Builds

More than fifteen machines built and tuned since 2020, for gaming and for workstation loads. This is where I learned to diagnose hardware methodically instead of guessing.

When
2020 to present
Role
Part selection, assembly, OS and driver setup, benchmarking, support
Tools
Windows and Linux installs, CPU and GPU benchmarks, thermal and stability testing

The process

Each build starts with what the machine is for. A gaming PC and a workstation want different balances of CPU, GPU, memory, and storage, and the budget decides where compromises go. From there it is part compatibility, assembly with attention to airflow and cable routing, then a clean operating system and driver install before anything else goes on.

Benchmarking

Every machine gets benchmarked before it is handed over. CPU and GPU tests establish a baseline, and thermals and clocks are logged under sustained load. The point is to find bottlenecks while the parts are still easy to swap. Measuring first means the fix is usually a setting or a single part, not a rebuild.

Troubleshooting

When a machine misbehaves I work through a written procedure instead of poking at it: isolate power, then memory, then storage, then GPU, checking one variable at a time. Keeping those steps documented cut the time it takes to resolve problems and built up a reference of which parts and settings tend to conflict. It is the same habit I now use when debugging embedded hardware.
