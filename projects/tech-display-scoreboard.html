Giant Seven-Segment Scoreboard

An oversized two-digit seven-segment display for the TMU Engineering Concrete Toboggan Team's tech display at the Great Northern Concrete Toboggan Race. Addressable LED strip segments, 3D printed housings, and a Wi-Fi microcontroller driving it all.

When
2025
Role
Tech Display Member: electronics, firmware, fabrication
Stack
Arduino C++, ESP8266 (Wemos D1 mini), addressable LED strips, 3D printing, soldering

The finished display counting up. Each digit is seven LED strip segments in printed housings.

The brief

Every team at the competition puts together a technical display, and ours needed a scoreboard that could be read from across a hall. Off-the-shelf displays at that size are expensive, so we built one: each digit is a set of seven segments, each segment is a length of addressable LED strip inside a printed housing, and one microcontroller drives the whole chain.

How it is built

SegmentsAddressable RGB LED strip cut to length, one strip per segment, soldered in a daisy chain
Housings3D printed segment shells that hold the strip and diffuse the light, printed in batches
ControllerWemos D1 mini on a driver board with a 5 V terminal block rated for the LED current
EnclosurePrinted box for the controller with a barrel-jack power input and connectors for each digit

Most of the hands-on work is wiring: each segment needs power, ground, and data, and every joint has to survive being packed, transported, and set up again. I did the soldering for the segment chains and the connectors between digits, and we printed the housings on the team's printer.

Control

The firmware is Arduino C++ on the ESP8266. Each digit maps to a fixed range of LEDs on the chain, and a lookup table turns a number into which segments to light. Because the controller has Wi-Fi, the score can be updated without touching the display. Both digits are built and running, as the video at the top shows.
